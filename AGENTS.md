# User preferences

- Do not write new automated tests for this project going forward, including `_test` files, unit tests, widget tests, or integration tests. Use static analysis, builds, and manual/visual checks for verification. Leave existing tests in place unless the user requests their removal.
- Treat UI/UX quality as a requirement for every interface change. Check alignment, spacing, hierarchy, responsive layout, keyboard access, and crowded or large-data states before calling the work complete. Visually verify desktop and mobile when possible; report any verification that could not be completed. Use consistent existing components, and integrate related controls into the same workflow instead of adding disconnected panels or comma-separated data lists.
