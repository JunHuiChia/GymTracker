# Bundled heading font

Lora variable font, downloaded from the official Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/lora

Font source: https://raw.githubusercontent.com/google/fonts/main/ofl/lora/Lora%5Bwght%5D.ttf
Licence: OFL-Lora.txt, the upstream SIL Open Font License. Font and licence are bundled locally; the app performs no font downloads.
